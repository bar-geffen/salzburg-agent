Accent is used only for time, links, and one primary action per screen. Bubble tints are the 8% versions: #F6EDE6 (Bar) and #E9EFE9 (Ori). Body 12.4:1, muted detail 5.5:1, mono labels 4.8:1 — all pass AA in direct sun.

Literata for titles and journal prose · Source Sans 3 for everything read fast · IBM Plex Mono for times, labels, flight numbers. Nothing below 14px except mono caps labels.

Patterns
Message Agent: no bubble, full width, serif heading + mono time column. User: tinted bubble, right-aligned, radius 20/20/6/20, mono name tag above. Sender is the tint, not an avatar.
Day card (Agenda) White card, 1px line, radius 18, padding 18. Serif date header, then rows of mono time (46px column) + name + one detail line. Today gets a mono accent tag and a sand tint; future days are white.
Auto journal The agent drafts one entry per day from that day's chat and shows it under Agenda with a mono "drafted from your chat" line. Two 44px actions: Edit (opens the text in place) or Keep. Nothing is ever posted without appearing here first.
Recommendation card Same shell as day card. Name left, category pill right (food / activity / day-trip = terracotta / green / ochre), one line of why-it-was-saved, then provenance ("From Bar’s chat · Tue") + Edit / Remove. Nothing is typed in by hand: the agent captures places as they come up in chat and they land sand-tinted at the top of Saved with Keep / Not this one, then settle into Kept as white cards.
Form input
52px fields, 48px buttons, 44px minimum for any tap target. Labels sit above, never inside. Editing happens in place in the panel — no modals.
